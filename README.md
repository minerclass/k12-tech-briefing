# K–12 technology briefing

A public, source-linked resource for K–12 technology directors and CTOs. E-Rate is the first topic. The site separates legal developments, proposals, applicant work, and leadership decisions.

Public site: https://minerclass.github.io/k12-tech-briefing/

## Use the guide

Open index.html in a browser, or visit the public site. Use the issue map, timeline, local review checklist, source library, leadership brief, and shareable summaries. Checklist progress stays in your browser; export/import it to transfer between devices. No checklist data are sent to a server.

## Source status

Snapshot: October 21, 2026. This is a curated reference, not an automatic news feed. Sources and summaries distinguish proposals, rulings, guidance, and advocacy. Verify current dates and requirements. No published social posts have been linked yet.

## Validation

Run node validate.mjs. The site has no external runtime dependencies. External source links require internet. Original guide interactions were tested over loopback HTTP; the public edition receives its own checks before release.

## Maintenance

Changes require review, a dated source record, and scoped validation. Do not add private editorial drafts, personal publication plans, progress exports, credentials, mailbox content, or district records. This repository contains only the public edition.
